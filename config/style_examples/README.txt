Drop .txt files in this folder to make them selectable as "Style Example" prose
references in the sidebar.

Each file should contain a sample of prose written in the voice you want the
generator to imitate (sentence rhythm, vocabulary, dialogue mechanics, pacing).

The engine treats these files STRICTLY as style/voice references. Their plot,
characters, and content are never intended to leak into generated stories -
only the way they are written matters.

This README.txt is ignored by the file picker.
