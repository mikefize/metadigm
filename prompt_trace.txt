PART 2 - WHERE TO ADJUST WHAT
====================================================================================================
Findings from this trace, most actionable first.

1. THE STYLE EXAMPLE OUTWEIGHS THE STYLE PROFILE BY ~57x
   style_gritty.txt contributes 158 chars to the system prompt.
   The style example block contributes 9,038 chars.
   If prose voice is not what you want, the example is doing nearly all the work and
   your style profile is close to a rounding error. Adjust config/style_examples/ first,
   config/style_*.txt second.

2. ONLY THE FIRST 8,000 CHARACTERS OF THE STYLE EXAMPLE ARE EVER SENT
   'Lifestyle Wedding Ch. 02.txt' is 47,494 chars. MAX_STYLE_EXAMPLE_CHARS
   (app.py:755) truncates it to 8,000 - about 16% of the file, and it is the
   FIRST 8,000, not a sample from across it. If the prose you actually want to imitate
   is later in that file, the model has never seen it. Either trim the file down to the
   8,000 chars you like best, or raise the constant.

3. THE OUTLINE IS PLANNED WITH NO STYLE INFORMATION AT ALL
   CALL 3 (the arc proposal) has a 38,594-char system prompt against
   47,790 for a chapter - the whole difference is the style guide and
   example, which generate_arc_proposal (app.py:1731) does not pass. Structure is decided
   'voiceless'. That is defensible, but it means tone-shaping edits never reach the
   outline, and the outline is what every chapter then follows.

4. THE CHAPTER TOKEN CEILING IS NOT WHAT LIMITS CHAPTER LENGTH
   9,000 words / 5 chapters = 1,800 words = ~10,800 chars = ~2,700 tokens.
   output_budget() has floor=16,000, so every chapter goes out with a 16,000-token
   ceiling - roughly 6x what the chapter should need. Short chapters are therefore a
   PROMPT problem, not a truncation problem. The target lands in the chapter prompt as a
   word count; if chapters run short, that instruction is what to sharpen.

5. HOW MUCH HISTORY EACH CHAPTER SEES
   Each chapter prompt carries: the full story bible, the full outline, the state log of
   every chapter so far, and the LAST 3,500 CHARACTERS of the previous chapter only.
   Continuity beyond that window survives only through the state log's one-line-per-
   chapter summaries. If chapter 5 forgets something from chapter 2, the state log is
   where to look, not the chapter text.

6. THE TWO EDITOR PASSES SEE DIFFERENT THINGS
   diagnose : 43,914-char system, NO style example, effort low
   rewrite  : 53,300-char system, style example INCLUDED, effort high
   The pass that decides WHAT is wrong cannot see your prose reference; only the pass
   that fixes it can. If the editor keeps flagging things that are deliberate features of
   your chosen voice, that asymmetry is why.
   The rewrite also receives the tail of the previous EDITED chapter (prev_tail) for
   continuity - visible as CALL 10 being ~1,200 chars shorter than CALLS 12-18.

7. THE INTENSITY SETTING IS A NUMERIC QUOTA
   'Aggressive' = a 50% sentence-rewrite quota written into the rewrite prompt
   (EDITOR_INTENSITY, app.py:846). Light Touch 15 / Standard 30 / Aggressive 50 /
   Ruthless 75. It is the single biggest lever on how much the editor actually changes.

8. THE 'IDENTICAL' STATUS IN THIS TRACE IS AN ARTIFACT - BUT THE CHECK IS REAL
   This run reports: 'The editor returned every chapter unchanged.'
   That is because the stub handed back the input unchanged. The same message in a REAL
   run means the editor genuinely returned the chapter unchanged - raise the intensity,
   or check the Changes tab to see whether it is only touching whitespace.

with the engine off, then a third time because the third time was when she usually found the
seam. There was no seam. Every settlement inside ninety days, every claimant signing the same
satisfaction language, every signature a little too even.

Ashcroft met her in the lobby instead of the office, which was its own answer. "You read the
file," she said. Not a question. She had the kind of voice that made a room agree with her
before it knew what it was agreeing to.

"I read the file. I'd like the intake records behind it."

"Those belong to patients." Ashcroft's hand settled on the small of Nora's back, steering her
toward the corridor, and Nora let it happen for three steps before she registered that she had
let it happen. "Become one and they'd belong to you."

The room they gave her smelled faintly of citrus. On the table was a form, a pen, and a small
grey speaker already playing something under the threshold of hearing.
